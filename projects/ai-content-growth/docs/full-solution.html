第一部分：市场背景与需求分析

1.1 海外品牌做社媒营销的四大核心问题

问题1：多语言内容生产能力不足

出海品牌通常需要覆盖英语、西语、日语、法语、阿拉伯语等多个市场。多数团队只有1至2名中文母语创作者，外语文案依赖翻译或外包，导致：

  • 内容产量低，多市场只能“先做英语，再考虑其他市场”。
  • 多语言排期被拉长，热点追不上。
  • 外包翻译成本高、周期不可控，内容质量不稳定。

业务影响： 市场覆盖速度慢，品牌在非英语市场的存在感弱，错过增长窗口。

问题2：本地化停留在“翻译”层面

简单翻译会把中文逻辑、广告语气、文化梗直接搬到海外，常见问题包括：

  • 英文文案过度直白，缺少TikTok、Instagram原生语境。
  • 同一卖点在不同市场没有对应的生活场景。
  • 未识别文化禁忌、宗教敏感、平台社区规则。
  • 数字、单位、支付方式、节日节点未做本地适配。

业务影响： 内容点击率低、评论区出现负面反馈，甚至引发品牌风险。

问题3：爆款内容经验难以复用

运营经常发现“某条内容在北美爆了，但换一个市场、换一个账号就失灵”。原因不是运气，而是：

  • 爆款结构没有被拆解成可复用的方法。
  • 爆款经验存在个人脑子里，团队换人就流失。
  • 竞品爆款只被“看”，没有被结构化沉淀。
  • 没有把“爆款结构”和“品牌卖点”结合的能力。

业务影响： 每次创作都从零开始，无法把成功经验变成稳定的内容杠杆。

问题4：内容生产效率低，迭代速度慢

一条多语言社媒内容的标准流程往往是：研究选题、写初稿、内部评审、翻译、本地化校对、平台适配、排期发布。这个过程存在大量重复劳动：

  • 同一个产品卖点需要反复被重新表达。
  • 同一段爆款结构在不同平台重复人工改写。
  • 评审依赖个人经验，缺少统一质量标准。

业务影响： 单条内容生产耗时数小时到数天，A/B测试素材不足，增长实验跑不起来。

第二部分：竞品分析

2.1 选品逻辑

选择HeyGen、Runway、Pika、Opus Clip，是因为它们分别代表四类AI内容产品方向：

  • HeyGen：AI视频与多语言本地化。
  • Runway：专业AI视频生成与编辑。
  • Pika：低门槛短视频生成。
  • Opus Clip：长视频到短视频的内容复用。

第三部分：产品机会发现

机会1：品牌内容一致性

  • 用户痛点：AI内容一多，品牌调性就漂移；多语言版本“长得不像一个品牌”。
  • 原因分析：通用AI缺少品牌知识，不了解定位、卖点、语气、禁忌。
  • 产品机会：建立品牌知识库Agent，作为所有生成任务的上下文来源，并提供品牌调性校验。

机会2：爆款经验复用

  • 用户痛点：团队知道某条内容爆了，但说不清为什么，也无法复制到其他市场。
  • 原因分析：爆款只被“浏览”，没有被拆解为结构、情绪、卖点等可复用要素。
  • 产品机会：爆款内容拆解Agent，把竞品内容变成结构化模板，并沉淀到爆款库。

机会3：本地化深度

  • 用户痛点：翻译版内容能看懂，但不像是为当地用户写的。
  • 原因分析：本地化停留在语言转换，缺少文化语境、用户场景、平台原生表达。
  • 产品机会：AI内容重写Agent，保留卖点与营销目标，按市场、人群、平台重写表达。

机会4：内容生产链路效率

  • 用户痛点：研究、写作、翻译、评审、改稿串行，单条内容生产周期过长。
  • 原因分析：大量环节是重复劳动，缺少一次生成多版本、一次质检多维度的工作流。
  • 产品机会：Agent化工作流，将“输入到产出”压缩为生成、评分、修订、确认的闭环。

机会5：内容质量判断

  • 用户痛点：评审靠个人感觉，不同人标准不一，发布后才发现内容吸引力不足。
  • 原因分析：缺少面向社媒内容的多维质量标准。
  • 产品机会：内容质量评估Agent，从吸引力、转化潜力、平台适配度三个维度给出可解释评分。

机会6：用户反馈反哺创作

  • 用户痛点：发布后的评论、完播、点赞数据没有被用来指导下一次创作。
  • 原因分析：内容生产与数据复盘割裂。
  • 产品机会：MVP后期增加“高表现内容回流”，让爆款结构库持续自我更新。

第四部分：产品定义

4.1 一句话产品定位

AI出海内容增长助手Agent，是面向出海品牌的一站式社媒内容生产Agent：以品牌知识库为底座，将竞品爆款拆解为可复用结构，再按目标市场、人群与平台生成多语言内容，并用内容质量评分驱动人工确认。

4.2 目标用户

  • 核心用户：跨境电商、DTC品牌、SaaS出海公司的市场/社媒运营团队。
  • 直接使用者：社媒负责人、内容创作者、增长操盘手。
  • 团队规模：1至50人，内容团队小而分散，缺少多语言全职创作者。

4.3 核心价值

核心价值 业务问题 AI如何解决
产能提升 多语言内容产出慢 一份Brief生成多市场、多平台候选稿，翻译+本地化一次完成
经验复用 爆款内容无法复制 爆款拆解Agent把成功内容转为结构模板，持续复用
品牌稳定 AI内容与品牌调性不一致 品牌知识库约束生成，质量评估拦截偏差
判断前置 发布后才发现内容不行 发布前给出吸引力、转化潜力、平台适配度评分与修改建议
决策闭环 内容效果无法反哺创作 高表现内容回流爆款库，形成增长飞轮

4.4 产品原则

  1. AI生成，人工把关：AI负责产能，人负责品牌判断和最终发布。
  2. 结构化内容资产：爆款结构、品牌知识、内容评分都可查询、可复用。
  3. 结果可解释：评分必须给出理由，不输出“黑盒结论”。
  4. MVP只验证核心假设：不追求全功能SaaS，优先验证“效率提升+质量可用”。

第五部分：功能设计（MVP）

5.1 MVP功能总览

功能 输入 输出 核心价值
爆款内容拆解Agent 竞品文案/视频脚本/文字稿 用户画像、内容结构、情绪触发点、核心卖点、爆款原因 把爆款经验变成可复用模板
AI内容重写Agent 原始内容或拆解模板+品牌知识+目标市场/平台 多语言多版本内容 保留卖点，完成表达与场景本地化
品牌知识库 品牌手册、产品详情、历史内容 结构化品牌资产 保证AI生成符合品牌调性
内容质量评估 生成内容+品牌知识+平台规则 三维评分+原因+修改建议 把主观评审变成可量化判断

5.2 功能1：爆款内容拆解Agent

输入：

  • 竞品文案、视频脚本、口播文字稿。
  • 可选：内容链接、平台、发布时间、账号类型。

输出：

输出项 说明
用户画像 这条内容写给谁：年龄、身份、核心诉求、内容消费场景
内容结构 开头钩子、节奏转折、卖点呈现、行动号召的拆解
情绪触发点 好奇、焦虑、认同、惊喜、社交证明等触发机制
核心卖点 被强调的产品价值与证据
爆款原因 结合结构、情绪、平台、人群给出的推断

产品要点：

  • 拆解必须引用原文片段，不输出无依据的“爆款结论”。
  • 拆解结果可一键保存为“内容模板”，供重写Agent使用。
  • 同一竞品可拆出多套结构，便于A/B测试。

5.3 功能2：AI内容重写Agent

要求：不是简单改写。

必须保留：

  • 核心卖点。
  • 营销目标：曝光、互动、转化、涨粉等。
  • 品牌约束：语气、身份、禁忌。

必须优化：

  • 表达方式：按平台语言习惯重写，避免翻译腔。
  • 用户场景：替换为当地用户真实生活场景。
  • 文化适配：节日、数字、货币、生活方式、梗文化。

MVP输出：

  • 每个任务默认生成3个内容变体。
  • 每个变体标注“保留的卖点”“本地化改动”“目标平台”。
  • 用户可对变体做评分、收藏、继续生成。

5.4 功能3：品牌知识库

支持三类核心知识：

类型 示例
品牌定位 品牌一句话、目标人群、价值主张、品牌性格
产品卖点 核心功能、差异点、证据、常见误解
目标市场 覆盖市场、文化禁忌、热门平台、语言偏好

产品要点：

  • 支持从品牌手册、商品详情、历史内容批量导入。
  • 每次生成任务自动检索相关知识，注入Prompt。
  • 提供“品牌调性校验”，质量评估时检查是否偏离品牌知识。
  • 支持版本管理，市场策略变化后可追溯。

5.5 功能4：内容质量评估

输出内容评分：

维度 评估重点 分值
吸引力 钩子强度、情绪价值、信息密度 0至100
转化潜力 卖点清晰度、证据强度、行动号召 0至100
平台适配度 平台格式、语言风格、社区规则 0至100

产品要点：

  • 总分低于阈值时，AI给出具体修改建议并引导重新生成。
  • 每个分数必须带“原因+原文引用”，不做无解释评分。
  • 支持人工评审记录，沉淀为后续评估标准。

6.2 每一步解决的问题

环节 设计内容 解决的问题
输入 结构化收集任务类型、原始内容、目标市场、平台、营销目标 避免信息缺失导致生成跑偏
Prompt处理 按任务动态组装角色、上下文、约束、输出格式 让一次通用模型能力变成稳定的岗位化能力
知识检索 从品牌知识库、爆款库、平台规范、市场禁忌中检索相关内容 减少幻觉，让生成有品牌依据和市场依据
LLM生成 多路生成候选，控制长度、视角、语言 提高多样性，给用户足够选择
质量检查 三维评分、事实一致性、品牌调性、文化风险、平台格式检查 把“发布后才知道好坏”变成“发布前先把关”
输出 结构化内容+评分+修订建议+人工确认 保证人在环，符合品牌决策流程

6.3 为什么这样设计

  • 知识检索前置：品牌知识库决定“像不像这个品牌”，检索越准，生成越稳。
  • 生成与评估分离：用生成Agent负责创意，用评估Agent负责把关，避免“自己写自己评分”的盲区。
  • 人工确认保留：MVP阶段不追求全自动发布，让用户看到AI的推理和改动，建立信任。
  • 数据回流：被用户采纳的内容可沉淀到爆款库，让系统越用越懂品牌。

6.4 真实LLM接入

原型已预留真实LLM后端能力：

  • 使用LangChain连接OpenAI兼容模型。
  • 未配置API Key时自动回退本地模拟引擎。
  • 前端自动检测后端服务，连接成功后状态显示“真实LLM引擎”。
  • 后续可替换为Coze、Dify等企业级Agent平台。

第七部分：Prompt工程设计

7.1 设计原则

  1. 角色明确：告诉模型“你是谁、为谁工作”。
  2. 上下文充分：品牌知识、原始内容、目标市场全部注入。
  3. 约束可验证：卖点保留、事实不新增、禁忌不触碰。
  4. 输出结构化：先给JSON，再给可读文案。
  5. 可重试：质量不达标时，用评分结果驱动二次生成。

7.2 核心Prompt模板：爆款内容拆解

角色：
你是一名资深出海社媒内容策略分析师，擅长拆解TikTok、Instagram、
YouTube Shorts等平台的爆款内容。

任务：
拆解用户提供的竞品内容，输出结构化爆款分析。

上下文：
品牌所属行业：{{行业}}
目标市场：{{市场}}
原始内容：{{竞品文案或视频脚本}}

限制条件：
1. 所有结论必须引用原文片段，禁止编造数据。
2. 用户画像只能依据内容中的表达推断，并标注证据。
3. 爆款原因是推断，需要区分“内容事实”和“策略推断”。

输出格式：
JSON，包含：
- user_profile：用户画像及证据
- content_structure：内容结构
- emotion_triggers：情绪触发点
- core_selling_points：核心卖点
- virality_reasons：爆款原因

7.3 核心Prompt模板：AI内容重写

角色：
你是一名熟悉欧美、东南亚、日韩等市场的出海品牌内容策划，
擅长按品牌调性重写多语言社媒内容。

任务：
基于原始内容或爆款模板，生成适合{{目标市场}}和{{目标平台}}的内容变体。

上下文：
品牌知识库：{{品牌定位、产品卖点、语气、禁忌}}
原始内容：{{原文或爆款拆解模板}}
营销目标：{{曝光/互动/转化/涨粉}}

限制条件：
1. 不得删除或弱化核心卖点。
2. 不得新增产品事实，如价格、功效、认证。
3. 必须做文化适配，避免直译、翻译腔和当地禁忌。
4. 每个变体必须说明“保留什么、改了什么、为什么改”。

输出格式：
先输出JSON元信息，再输出3个内容变体。

7.4 核心Prompt模板：内容质量评估

角色：
你是出海品牌社媒内容质量评审，评审标准严格、判断可解释。

任务：
对生成内容进行三维评分，并给出修改建议。

上下文：
品牌知识库：{{品牌知识}}
目标平台：{{平台}}
营销目标：{{营销目标}}
待评估内容：{{内容}}

限制条件：
1. 每个分数必须附原因和原文引用。
2. 若出现事实风险、文化风险，必须单列警告。
3. 修改建议必须具体到可执行。

输出格式：
JSON，包含：
- scores：吸引力、转化潜力、平台适配度
- verdict：通过/需修改/不建议发布
- warnings：风险清单
- suggestions：修改建议

第八部分：MVP验证

8.1 验证假设

核心假设：出海品牌内容团队使用Agent后，可以在保持品牌调性的前提下，显著提升多语言社媒内容生产效率。

8.2 测试用户

用户类型 人数 说明
品牌社媒负责人 3人 判断品牌一致性与流程可用性
内容创作者 4人 高频使用，记录生产耗时与修改次数
增长操盘手 2人 验证多版本素材生成与A/B测试价值
本地化/翻译角色 1人 校验文化适配质量

8.3 测试任务

  1. 上传一条竞品TikTok脚本，完成爆款拆解。
  2. 使用拆解模板+品牌知识库，为同一产品生成英语、西语、日语三个市场变体。
  3. 针对目标平台（TikTok/Instagram）生成3个内容变体。
  4. 使用质量评估对内容评分并修改到“通过”。
  5. 完成满意度问卷与15分钟访谈。

8.4 评价指标

类型 指标 定义
效率 单条内容生产时间 从输入Brief到确认终稿的耗时
效率 人工修改次数 用户修改AI初稿的轮次
质量 首版通过率 未修改或仅小幅修改即通过的比例
质量 品牌调性一致率 用户判断符合品牌调性的内容占比
质量 本地化认可度 当地用户/审校认为内容自然可用的比例
体验 用户满意度 5分量表，重点看“愿意持续使用”
商业 素材产出量 单位时间可生成的内容变体数
商业 使用意愿 是否愿意纳入正式工作流或付费

8.5 模拟验证指标（非真实商业数据）

说明：以下为MVP设计阶段的目标值，用于验证方案是否可执行，不代表已完成的真实实验结果。

指标 人工基线（行业经验估算） Agent模拟目标
单条多语言内容生产时间 90至120分钟 30至45分钟
人工修改次数 3至4轮 不超过2轮
首版通过率 约40% 不低于75%
品牌调性一致率 依人而异 不低于80%
单次Brief产出变体数 1至2个 3至5个
用户满意度 无AI对照 4分以上（5分制）

8.6 验证方法与风险

  • 验证方法：可点击原型或Demo演示，8至10名用户完成5个任务，配合两周使用日志、满意度问卷和深度访谈。
  • 补充验证：若可拿到品牌历史内容数据，可对比同团队同类型内容的真实生产耗时，但MVP阶段不虚构数据。
  • 主要风险：样本量小、行业差异大、文化适配主观性强；因此用“评分一致率”和“用户访谈交叉验证”降低偏差。
