2. 产品概述

2.1 产品背景

出海品牌在海外社媒营销中普遍面临四类问题：

  1. 多语言内容产能不足，非英语市场覆盖慢。
  2. 本地化停留在翻译层面，缺少文化语境与用户场景。
  3. 爆款内容经验难以沉淀和复用，每次创作从零开始。
  4. 内容生产链路长，评审、改稿、平台适配重复劳动多。

2.2 产品定位

BrandPilot AI是一款面向出海品牌团队的AI Native社媒内容生产Agent：

以品牌知识库为底座，将竞品爆款拆解为可复用结构，再按目标市场、人群与平台生成多语言内容，并用内容质量评分驱动人工确认。

2.3 产品目标

MVP阶段不追求商业级SaaS能力，只验证一个核心假设：

AI能否帮助出海品牌提升海外社媒内容生产效率。

2.4 成功标准

MVP验证通过条件：

指标 目标值 说明
单条多语言内容生产时间 30至45分钟 模拟目标，非真实商业数据
人工修改轮次 不超过2轮 模拟目标
首版通过率 不低于75% 模拟目标
品牌调性一致率 不低于80% 模拟目标
用户满意度 4分以上（5分制） 模拟目标

2.5 产品原则

  1. AI生成，人工把关。
  2. 结构化内容资产：爆款结构、品牌知识、内容评分可查询、可复用。
  3. 结果可解释：评分必须给出理由，不做无解释输出。
  4. 生成与评估分离，避免“自己写自己评分”的盲区。
  5. 所有量化结果明确标注模拟属性，不虚构真实商业数据。

3. 目标用户与使用场景

3.1 用户画像

画像 用户角色 核心任务 核心痛点 使用AI后的变化
A 品牌全球社媒负责人 制定内容策略、管理多市场内容日历、把控品牌调性 内容一致性难保证、评审链路长、多语言产能不足 输入Brief和品牌知识库，AI先产出候选稿，负责人只做策略把关和终审
B 品牌内容创作者 找选题、写脚本、改文案、平台适配 创作灵感枯竭、爆款套路说不清、重复改稿 竞品爆款一键拆解，AI按品牌卖点重写多个变体，创作者集中做创意判断
C 增长/投放操盘手 生产付费与自然流量素材、跑A/B测试 素材版本不够、测试周期长、爆款钩子难复制 基于高表现内容快速生成钩子与卖点变体，测试节奏加快

3.2 核心使用场景

  1. 用户粘贴竞品文案或视频脚本，Agent输出结构化爆款拆解。
  2. 用户选择多个目标市场与平台，Agent批量生成本地化内容变体。
  3. 用户在品牌知识库中维护品牌定位、卖点、市场与禁忌，约束后续生成。
  4. 用户对生成内容进行质量评估，依据评分和修改建议完成终稿。
  5. 用户确认交付，内容写入内容记录并支持导出JSON。

5. 功能需求

F1 爆款内容拆解Agent

优先级：P0

用户故事

作为品牌内容创作者，我希望把竞品文案或视频脚本拆解成用户画像、内容结构、情绪触发点、核心卖点和爆款原因，以便快速复用成功的爆款结构。

功能描述

用户输入竞品文案、视频脚本或口播文字稿，Agent输出结构化爆款分析，并支持保存为内容模板。

输入

字段 必填 说明
竞品文案/视频脚本 是 文本内容
来源平台 否 TikTok、Instagram、YouTube Shorts
账号类型 否 DTC品牌、生活博主、测评账号

输出

输出项 说明
用户画像 目标用户、核心诉求、消费场景、内容证据
内容结构 钩子、转折、卖点呈现、行动号召
情绪触发点 时间焦虑、效率认同、场景代入、社交认同
核心卖点 被强调的产品价值与证据
爆款原因 内容事实与策略推断分离

业务规则

  1. 所有结论必须引用原文片段，禁止编造数据。
  2. 用户画像只能依据内容中的表达推断，并标注证据。
  3. 爆款原因属于策略推断，需要区分“内容事实”和“策略推断”。
  4. 拆解结果可一键保存到爆款库。

验收标准

GIVEN 用户输入一条竞品TikTok脚本
WHEN 点击“开始拆解”
THEN Agent按六个步骤运行
AND 输出用户画像、内容结构、情绪触发点、核心卖点、爆款原因
AND 每个输出项均有对应内容依据
AND 用户可以保存到爆款库

F2 AI内容重写Agent

优先级：P0

用户故事

作为品牌社媒负责人，我希望一次选择多个市场批量生成内容变体，以便一份Brief产出多个市场的可用内容，而不是逐市场重复翻译和改写。

功能描述

用户基于爆款拆解结果或原始内容，选择目标市场与平台，Agent生成多个本地化内容变体。

输入

字段 必填 说明
爆款拆解结果/原始内容 是 来自F1或用户输入
目标市场 是 多选，默认美国、英国、日本，可选新加坡
目标平台 是 TikTok、Instagram、YouTube Shorts
变体数量 否 每个市场生成2个或3个

输出

每个市场输出2至3个内容变体，包含：

输出项 说明
内容正文 本地化后的文案
市场标签 US、UK、JP、SG
平台标签 目标平台
保留卖点 未被删除或弱化的核心卖点
本地化改动 表达方式、用户场景、文化适配说明

业务规则

  1. 不得删除或弱化核心卖点。
  2. 不得新增产品事实，如价格、功效、认证。
  3. 必须做文化适配，避免直译、翻译腔和当地禁忌。
  4. 每个变体必须说明“保留什么、改了什么、为什么改”。

验收标准

GIVEN 已完成爆款拆解
WHEN 选择美国、英国、日本三个市场和2个变体数量
AND 点击“生成变体”
THEN 生成6个内容变体
AND 每个变体带市场标签、平台标签、保留卖点和本地化改动

F3 品牌知识库

优先级：P0

用户故事

作为品牌负责人，我希望把品牌定位、产品卖点、目标市场、语气和禁忌维护在一个知识库中，以便AI生成内容始终符合品牌调性。

功能描述

品牌知识库支持品牌信息编辑、卖点维护、市场维护、禁忌维护，并在生成和评估时作为上下文约束。

字段

字段 说明
品牌名称 品牌展示名称
品牌定位 品牌一句话定位
目标人群 核心用户群
品牌语气 语气与表达约束
产品卖点 可增删的核心卖点列表
目标市场 可增删的市场列表
品牌禁忌 可增删的表达禁忌

业务规则

  1. 每次生成任务自动读取品牌知识并注入上下文。
  2. 质量评估时执行品牌调性校验。
  3. 品牌知识修改后立即生效，并在当前任务中可见。

验收标准

GIVEN 用户在品牌知识库新增一个产品卖点
WHEN 保存品牌知识并进入内容重写
THEN 生成内容中可看到该卖点被保留
AND 品牌名称在侧边栏同步更新

F4 内容质量评估

优先级：P0

用户故事

作为增长操盘手，我希望生成内容在发布前获得吸引力、转化潜力和平台适配度评分，以便提前发现低质量内容并完成修改。

功能描述

对指定内容变体进行三维评分，输出分数、原因、修改建议和最终结论。

输出

维度 评估重点 分值
吸引力 钩子强度、情绪价值、信息密度 0至100
转化潜力 卖点清晰度、证据强度、行动号召 0至100
平台适配度 平台格式、语言风格、社区规则 0至100

结论规则

  1. 平均分不低于80：通过。
  2. 平均分70至79：需修改。
  3. 平均分低于70：不建议发布。

验收标准

GIVEN 用户选择一个已生成的内容变体
WHEN 点击“开始评估”
THEN 输出三个维度的评分
AND 每个分数附原因与原文引用
AND 输出“通过/需修改/不建议发布”结论
AND 修改建议具体到可执行

F5 Agent工作流

优先级：P0

功能描述

所有Agent任务按照统一六步工作流运行：

输入
  ↓
Prompt处理
  ↓
知识检索
  ↓
LLM生成
  ↓
质量检查
  ↓
输出

界面要求

  1. 侧边栏显示当前任务状态。
  2. 进度条实时展示运行进度。
  3. Agent运行日志记录每个步骤及完成时间。
  4. 运行期间主操作按钮禁用，防止重复提交。
  5. 运行完成后恢复可操作状态。

验收标准

GIVEN 用户点击“开始拆解”
WHEN Agent开始运行
THEN 侧边栏逐步显示输入解析、Prompt处理、知识检索、LLM生成、质量检查、输出
AND 运行日志追加对应记录
AND 页面不出现重复提交

F6 内容管理与交付

优先级：P1

功能描述

支持爆款模板沉淀、内容记录、确认交付、复制内容和导出JSON。

业务规则

  1. 爆款库：保存拆解模板，可重新加载使用。
  2. 内容记录：保存已确认交付的内容、市场、平台、评分和状态。
  3. 导出JSON：导出当前任务、品牌知识、爆款库和内容记录。
  4. 新建任务：清空当前任务内容，品牌知识库保留。

F7 官网转化

优先级：P1

功能描述

产品官网首页用于展示BrandPilot AI的产品定位、Agent工作流、核心能力、模拟指标、定价与转化入口。

注册弹窗

字段 必填 说明
工作邮箱 是 邮箱格式校验
品牌名称 是 非空校验
目标市场 是 单选，默认美国

验收标准

GIVEN 用户点击“Start free”
WHEN 填写邮箱、品牌名称和目标市场并提交
THEN 显示“Workspace ready”
AND 可点击“Open Agent workspace”进入Agent原型

8. 非功能需求

  1. 首屏加载时间不超过2秒。

  4. 页面图片使用懒加载。

  1. 支持Chrome、Safari、Edge最新版本。
  2. 支持桌面、平板、移动端响应式布局。
  3. 不依赖外部网络资源，可离线演示。

  1. 正文文本与背景对比度满足WCAG AA。
  2. 所有交互元素可键盘操作，并显示可见焦点。
  3. 触控目标不小于44px。
  4. 支持系统“减少动态效果”设置。

8.4 数据与安全

  1. MVP阶段数据保存在浏览器本地，不涉及服务端存储。
  2. 邮箱字段进行格式校验，不采集敏感信息。
  3. 导出JSON仅包含演示数据。

真实LLM接入设计

MVP完成后，Agent工作流已预留真实LLM后端：

  • 后端使用LangChain连接OpenAI兼容模型。
  • 未配置API Key时自动回退本地模拟引擎。
  • 前端自动检测后端服务，连接成功后状态显示“真实LLM引擎”。
  • 后续可将LangChain替换为Coze、Dify等平台工作流。

12. 风险与依赖

风险 影响 应对
真实LLM输出质量不稳定 内容质量下降 保留质量评估与人工确认
文化适配主观性强 不同市场接受度差异大 引入本地审校角色参与验证
MVP样本量小 指标代表性不足 通过评分一致率与访谈交叉验证
品牌知识维护成本高 用户不愿持续维护 支持批量导入和默认模板
模拟数据被误认为真实数据 影响可信度 所有指标明确标注模拟属性
