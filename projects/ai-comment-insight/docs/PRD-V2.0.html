1. 产品重新定位

1.1 一句话定位

InsightPulse是一款面向出海品牌团队的AI用户洞察与增长决策Agent，将分散在Amazon、TikTok、Reddit等渠道的用户声音，转化为用户痛点洞察、产品优化建议、市场机会发现和内容增长方向。

1.2 从“评论分析工具”升级为“决策Agent”

维度 旧定位 新定位
产品角色 评论分析工具 用户洞察与增长决策Agent
核心产出 情感比例、主题列表 可执行的决策建议
用户关系 用户自己分析 AI先分析，再辅助人做判断
决策价值 告诉用户“有什么” 告诉用户“意味着什么、该做什么、先做什么”

1.3 核心价值

InsightPulse将用户声音转化为四类业务价值：

  1. 用户痛点洞察：知道用户为什么不满意。
  2. 产品优化建议：知道优先解决什么问题。
  3. 市场机会发现：知道哪里还有增长空间。
  4. 内容增长方向：知道下一批内容应该讲什么。

1.4 产品决策逻辑

InsightPulse的产品逻辑不是“生成一段分析”，而是：

用户声音
  ↓
理解用户表达
  ↓
识别问题与需求
  ↓
评估影响与商业价值
  ↓
输出优先级决策建议

2. 产品背景

2.1 行业背景

出海品牌进入新市场时，用户决策高度依赖真实评论和社媒反馈。

用户声音分布在多个渠道：

  • Amazon商品评论
  • TikTok评论区
  • Reddit产品讨论
  • Trustpilot评分
  • 客服反馈
  • 独立站用户评价

品牌需要回答三类问题：

  1. 用户对产品满意什么、不满意什么。
  2. 哪些问题值得优先改进。
  3. 下一阶段内容与增长方向是什么。

2.2 当前人工方式的问题

当前多数团队采用人工方式：

人工收集评论
  ↓
Excel整理
  ↓
人工分类
  ↓
经验判断

存在的问题：

问题 影响
效率低 5000条评论人工分析耗时数天
主观性强 不同人判断标准不一致
难发现隐藏需求 只看到高频表达，看不到潜在需求
覆盖有限 只能抽样，无法全量分析
决策滞后 分析完成时机会窗口已经过去

2.3 AI解决机会

LLM具备四项关键能力：

  1. 语义理解：理解用户真实表达，而不是只看关键词。
  2. 情感分析：识别正面、中性、负面情绪。
  3. 主题归纳：把分散反馈聚类成结构化主题。
  4. 洞察生成：从数据中提炼问题、原因和建议。

InsightPulse的机会不是替代“人工分析”，而是把人工从“收集、整理、分类”中解放出来，让人把时间花在“判断和决策”上。

3. 用户画像与真实业务场景

3.1 用户1：海外品牌市场负责人

维度 内容
用户角色 跨境电商/DTC品牌市场负责人
工作场景 新品进入新市场，需要判断用户反馈和市场机会
当前任务 分析评论、判断产品是否满足市场需求、决定下一步策略
痛点 评论量大，人工分析慢；难以判断哪些问题是少数抱怨还是普遍问题
使用AI后 上传评论数据，快速获得痛点优先级、产品建议和市场机会

真实业务场景示例：

新品进入美国市场，需要分析5000条Amazon评论。市场负责人希望通过评论判断：

  • 用户最满意的功能是什么
  • 用户退货和差评的核心原因是什么
  • 下一阶段是否应该扩充容量、改进续航或调整营销卖点

3.2 用户2：产品经理

维度 内容
用户角色 出海品牌产品经理
工作场景 根据用户反馈确定产品迭代方向
当前任务 整理用户问题、评估优先级、输出产品改进建议
痛点 用户反馈表达分散，难以判断优先级；缺少影响人数和商业价值评估
使用AI后 获得P0/P1/P2排序，依据影响人数、情绪强度和商业价值做决策

真实业务场景示例：

多用户反馈“电池不耐用”，但产品经理无法判断这是个别抱怨还是核心问题。使用InsightPulse后，AI将相关评论聚类，并计算影响人数、情绪强度和商业价值，输出“是否优先优化电池”的决策建议。

3.3 用户3：内容运营

维度 内容
用户角色 品牌内容运营/社媒负责人
工作场景 需要为TikTok、Instagram等平台生产增长内容
当前任务 寻找内容选题、确定营销角度、生产素材
痛点 选题缺少数据依据，容易自嗨；不确定用户真正关注什么
使用AI后 基于真实用户声音获得TikTok选题、广告方向和营销角度

真实业务场景示例：

内容运营需要为便携咖啡机生产下一批TikTok内容。通过InsightPulse发现用户高频提到“露营使用”“通勤不漏”“电池续航”，从而生成“露营实测”“通勤包防漏测试”“续航挑战”三个内容方向。

4.2 用户旅程拆解

阶段 用户行为 Agent处理 用户获得 决策价值
1 数据上传 上传CSV或粘贴评论 数据清洗与语言识别 数据可分析 降低数据准备成本
2 评论理解 等待分析 语义理解每条评论 结构化评论数据 不再逐条阅读
3 情感分析 查看情感分布 正面/中性/负面分类 情绪比例与代表评论 快速判断整体情绪
4 主题聚类 查看主题 自动归入续航、容量、密封等主题 主题数量与典型案例 知道用户在讨论什么
5 痛点识别 查看痛点 定位高频痛点与典型表达 影响人数与情绪强度 知道真正的问题
6 机会排序 查看优先级 按影响、情绪、商业价值排序 P0/P1/P2建议 知道先做什么
7 产品建议 查看产品机会 生成问题、原因、机会与方案 可执行建议 辅助产品决策
8 内容选题 查看内容方向 生成平台化选题与营销角度 TikTok选题与广告方向 辅助增长决策

5. AI Agent架构

5.1 整体架构

InsightPulse由四个Agent协作完成从“用户声音”到“业务决策建议”的完整链路。

Data Understanding Agent
  ↓
Insight Analysis Agent
  ↓
Product Strategy Agent
  ↓
Growth Content Agent

每个Agent都有明确的输入、处理逻辑和输出结果。上游Agent的输出作为下游Agent的上下文，保证决策链路可追溯。

5.2 Agent 1：Data Understanding Agent

职责：

负责数据清洗、语言识别和评论理解。

输入：

  • Amazon Review
  • TikTok评论
  • Reddit反馈
  • CSV文件
  • 人工粘贴的评论文本

处理逻辑：

  1. 识别评论语言与来源渠道。
  2. 清洗重复、无效和无关内容。
  3. 将评论转换为结构化文本。
  4. 标记每条评论的产品对象。

输出结果：

  • 结构化评论数据
  • 语言与渠道标签
  • 可分析评论数量
  • 无效数据过滤说明

5.3 Agent 2：Insight Analysis Agent

职责：

负责情感分析、痛点聚类和用户需求提取。

输入：

  • Data Understanding Agent输出的结构化评论

处理逻辑：

  1. 识别正面、中性、负面情绪。
  2. 按产品主题聚类用户反馈。
  3. 提取每条评论背后的用户需求。
  4. 选择代表评论作为证据。

输出结果：

  • 情感分布
  • 主题聚类结果
  • 影响人数
  • 典型案例与原文引用

5.4 Agent 3：Product Strategy Agent

职责：

负责生成产品优化建议并完成优先级排序。

输入：

  • Insight Analysis Agent输出的痛点与需求

处理逻辑：

  1. 评估影响人数。
  2. 评估情绪强度。
  3. 评估商业价值。
  4. 输出P0/P1/P2优先级。

输出结果：

  • 用户问题
  • 原因分析
  • 产品机会
  • 建议方案
  • 优先级结论

5.5 Agent 4：Growth Content Agent

职责：

负责生成营销内容方向。

输入：

  • Product Strategy Agent输出的优先级建议
  • 目标平台
  • 目标市场

处理逻辑：

  1. 根据用户痛点生成内容主题。
  2. 按平台特征适配表达方式。
  3. 输出可执行的内容方向与营销角度。

输出结果：

  • TikTok选题
  • 广告方向
  • 营销角度
  • 内容表达建议

6. 功能模块设计

F1 多渠道数据输入

功能说明：

支持Amazon Review、TikTok评论、Reddit反馈和CSV文件上传。

用户价值：

用户不需要先整理数据，直接上传或粘贴即可开始分析。

输入：

  • 渠道评论
  • CSV文件
  • 文本粘贴
  • 目标市场
  • 时间范围

输出：

  • 可分析评论数量
  • 数据来源标签
  • 数据清洗结果

F2 AI用户情感分析

功能说明：

自动识别评论情感，输出情绪比例、趋势变化和代表评论。

用户价值：

用户快速判断整体用户情绪，不再逐条阅读。

输出：

  • 正面/中性/负面占比
  • 趋势变化
  • 代表评论

F3 用户痛点聚类

功能说明：

将分散反馈自动归入续航、容量、密封、加热速度等主题。

用户价值：

用户看到“用户在讨论什么”，而不是“每条评论写了什么”。

输出：

  • 主题数量
  • 影响人数
  • 典型案例

F4 用户需求优先级排序

功能说明：

根据影响人数、情绪强度和商业价值输出P0/P1/P2。

用户价值：

用户知道“先解决什么问题”，而不是“所有问题都重要”。

排序依据：

维度 说明
影响人数 评论数量和涉及用户规模
情绪强度 负面表达强烈程度
商业价值 对销量、复购和品牌的影响

F5 AI产品机会生成

功能说明：

将痛点转化为产品优化建议。

输出：

  • 用户问题
  • 原因分析
  • 产品机会
  • 建议方案

F6 AI内容增长建议

功能说明：

根据用户洞察生成TikTok选题、广告方向和营销角度。

用户价值：

内容团队不再靠猜，而是基于真实用户声音生产内容。

F7 洞察报告生成

功能说明：

支持生成PDF、JSON和PRD格式报告。

用户价值：

洞察结果可以直接同步给市场、产品和增长团队。

7. 竞品分析

7.1 ChatGPT

维度 内容
产品定位 通用AI对话助手
优势 理解能力强，可自由分析文本
不足 需要用户自己整理数据；缺少结构化决策链路；结果不可复用
InsightPulse机会点 提供数据输入到决策输出的完整工作流，而不是单次问答

7.2 MonkeyLearn

维度 内容
产品定位 文本分析与分类工具
优势 分类模型成熟，适合固定标签体系
不足 需要配置模型和标签；偏向工具，不输出业务决策建议
InsightPulse机会点 从“分类工具”升级为“决策Agent”，输出优先级和行动建议

7.3 Glean

维度 内容
产品定位 企业知识搜索与AI助手
优势 企业知识整合能力强
不足 面向内部知识，不面向外部用户声音分析
InsightPulse机会点 专注出海用户声音，形成垂直场景决策闭环

7.4 竞品总结

产品 解决什么 未解决什么 InsightPulse机会
ChatGPT 通用文本理解 无结构化决策链路 Agent化工作流
MonkeyLearn 文本分类 无业务建议 痛点到机会的转化
Glean 企业知识搜索 不分析外部用户声音 垂直出海场景

8. MVP设计

8.1 MVP目标

验证核心假设：

AI是否能够帮助出海品牌快速完成用户洞察，并辅助业务决策。

8.2 MVP必须包含

  • CSV评论上传
  • AI分析
  • 痛点聚类
  • 机会生成
  • 报告导出

8.3 MVP暂不包含

  • 实时API接入
  • 复杂数据采集
  • 多账号权限体系
  • 跨市场实时趋势看板

8.4 MVP成功标准

指标 目标
分析完成率 不低于90%
报告导出率 不低于60%
人工分析时间减少 50%以上
AI洞察准确性评价 4分以上（5分制）

以上为模拟目标值，非真实商业数据。

9. 数据指标体系

9.1 用户指标

指标 定义 目标
分析完成率 发起分析并成功完成的比例 不低于90%
报告导出率 完成分析后导出报告的比例 不低于60%
用户留存率 二次使用分析功能的比例 不低于40%

9.2 效率指标

指标 定义 目标
人工分析时间减少比例 使用InsightPulse后人工分析耗时下降比例 50%以上
报告生成时间 从上传数据到获得洞察的时间 30秒内

9.3 质量指标

指标 定义 目标
AI洞察准确性评价 用户对洞察结果与原文一致性的评分 4分以上（5分制）
痛点识别准确率 聚类主题与用户真实表达的匹配度 不低于80%
报告修改率 用户需要大幅修改报告的比例 不高于30%

9.4 商业指标

指标 定义 目标
有效市场机会数量 用户认可并计划跟进的机会数 每周不少于2个
内容选题采用率 被内容团队采用的AI选题比例 不低于60%
产品改进采纳率 被产品团队纳入迭代的建议比例 不低于40%
