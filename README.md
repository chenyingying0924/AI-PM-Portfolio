# AI产品经理作品集

## 目录结构

```text
/
├── index.html                         作品集导航首页
├── projects/
│   ├── ai-content-growth/             项目1：AI出海内容增长助手 Agent
```

## 使用说明

1. 直接打开 `index.html` 查看作品集导航。
2. 每个项目使用独立文件夹，结构清晰，方便单独展示和后续扩展。
3. 上传GitHub并开启GitHub Pages后，`index.html` 作为作品集首页。
