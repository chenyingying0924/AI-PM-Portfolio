## 2. AI出海内容增长助手 Agent

### 2.1 基本信息

- 项目类型：AI Native MVP / 自驱项目
- 角色：AI产品设计、Agent工作流设计、Prompt工程、原型搭建
- 目标用户：出海品牌社媒负责人、内容创作者、增长操盘手
- 竞品参考：HeyGen、Runway、Pika、Opus Clip

### 2.2 背景与痛点

出海品牌做海外社媒时面临四类问题：

1. 多语言内容产能不足
2. 本地化停留在翻译，存在“机翻味”
3. 爆款经验无法复用
4. 内容生产链路过长

### 2.3 产品定义

以品牌知识库为底座，把竞品爆款拆解为可复用结构，再按市场、人群和平台生成多语言内容，并通过质量评分驱动人工确认。

四大功能：

1. 爆款内容拆解Agent
2. AI内容重写Agent
3. 品牌知识库
4. 内容质量评估

### 2.4 Agent工作流

```text
输入分析
  ↓
Prompt处理
  ↓
知识检索
  ↓
LLM生成
  ↓
质量检查
  ↓
输出交付
```

### 2.5 核心Prompt

- 爆款结构解析Prompt
- 多语言文化适配Prompt
- 内容多维评分Prompt

### 2.6 MVP与模拟验证目标

- 测试用户：10名目标用户
- 测试任务：5个核心任务
- 指标体系：生产效率、内容质量、用户体验
- 单条内容生产时间：90至120分钟降至30至45分钟（模拟）
- 人工修改轮次：控制在2轮以内（模拟）
- 首版通过率：75%以上（模拟）

### 2.7 技术与真实LLM

- 原型：HTML/CSS/JavaScript
- 官网：React + Webpack + GSAP
- 真实LLM后端：LangChain + OpenAI兼容接口
- 无API Key时：自动回退本地模拟引擎

### 2.8 交付物

- 可交互Agent原型
- 商业化产品官网
- 20页PDF作品集
- PRD
- 完整产品方案

### 2.9 简历可用关键词

出海品牌、社媒内容增长、多语言内容、本地化、爆款拆解、品牌知识库、Agent工作流、Prompt工程、MVP验证、React原型、LangChain。

## 3. AI海外用户声音洞察 Agent

### 3.1 基本信息

- 项目类型：AI Agent产品 / 自驱项目
- 角色：AI产品设计、四Agent架构设计、原型搭建
- 目标用户：海外品牌市场负责人、产品经理、内容运营
- 相关工具参考：ChatGPT、MonkeyLearn、Glean

### 3.2 背景与痛点

用户声音分散在Amazon、TikTok、Reddit和客服反馈中：

- 人工分析效率低
- 判断主观性强
- 隐藏需求难发现
- 反馈难以转化为业务决策

### 3.3 产品定位

面向出海品牌团队的AI用户洞察与增长决策Agent，把用户声音转化为：

1. 用户痛点洞察
2. 产品优化建议
3. 市场机会发现
4. 内容增长方向

### 3.4 四Agent架构

| Agent | 职责 | 输出 |
| --- | --- | --- |
| Data Understanding Agent | 数据清洗、语言识别、评论理解 | 结构化评论数据 |
| Insight Analysis Agent | 情感分析、痛点聚类、需求提取 | 情感分布、主题聚类、典型案例 |
| Product Strategy Agent | 影响人数、情绪强度、商业价值评估 | P0/P1/P2产品机会 |
| Growth Content Agent | 平台适配、营销角度生成 | TikTok选题、广告方向 |

### 3.5 功能模块

- F1 多渠道数据输入：Amazon、TikTok、Reddit、CSV
- F2 AI用户情感分析：情绪比例、趋势、代表评论
- F3 用户痛点聚类：主题数量、影响人数、典型案例
- F4 用户需求优先级排序：P0/P1/P2
- F5 AI产品机会生成：问题、原因、机会、方案
- F6 AI内容增长建议：TikTok选题、广告方向
- F7 洞察报告生成：JSON、PRD、PDF

### 3.6 MVP与模拟验证目标

- 测试用户：10名目标用户
- 测试任务：5个核心任务
- 洞察报告生成时间：30秒内（模拟）
- 痛点识别准确率：80%以上（模拟）
- 内容选题采用率：60%以上（模拟）
- 每周有效市场机会：2个以上（模拟）

### 3.7 简历可用关键词

用户声音洞察、Amazon评论、TikTok评论、Reddit反馈、情感分析、痛点聚类、需求优先级、市场机会、内容增长、四Agent架构、CSV、JSON/PRD/PDF报告。

## 4. PRD Copilot AI Product Manager Agent

### 4.1 基本信息

- 项目类型：AI Product Manager Agent / 自驱项目
- 角色：AI产品设计、五Agent架构设计、原型搭建
- 目标用户：产品经理、产品负责人、产品新人/实习生
- 相关工具参考：ChatGPT、Notion AI、Jira AI

### 4.2 背景与痛点

产品经理大量时间消耗在信息整理和PRD撰写上：

- 信息碎片化
- 重复整理成本高
- 新人经验不足
- PRD质量依赖个人能力

### 4.3 产品定位

面向产品团队的AI需求分析与产品设计Agent，通过理解用户声音、业务目标和产品规范，自动完成需求洞察、方案设计、PRD生成和质量评审。

### 4.4 五Agent架构

| Agent | 职责 | 输出 |
| --- | --- | --- |
| Research Agent | 理解输入资料 | 用户问题、需求机会、关键洞察 |
| Requirement Analyst Agent | 需求分析 | 用户故事、需求列表、P0/P1/P2 |
| Product Designer Agent | 产品方案设计 | 功能模块、用户流程、页面结构 |
| PRD Writer Agent | PRD生成 | 背景、目标、用户、功能、流程、验收标准 |
| Review Agent | 模拟产品负责人评审 | 问题列表、修改建议、质量评分 |

### 4.5 功能模块

- F1 多源需求输入：文本、访谈、会议纪要、竞品分析
- F2 AI需求洞察：用户问题、场景、机会点
- F3 用户画像生成：目标、行为、痛点
- F4 AI需求池管理：需求描述、用户价值、业务价值、优先级
- F5 功能方案设计：功能模块、页面流程、业务规则
- F6 PRD自动生成：标准PRD结构
- F7 AI PRD Review：问题、建议、质量评分

### 4.6 MVP与模拟验证目标

- 测试用户：10名目标用户
- 测试任务：5个核心任务
- PRD初稿生成时间：30秒内（模拟）
- 需求完整率：85%以上（模拟）
- PRD完整度评分：85分以上（模拟）
- 评审通过率：提升30%（模拟）

### 4.7 简历可用关键词

AI Product Manager Agent、需求洞察、用户画像、需求池、功能设计、PRD生成、AI Review、五Agent架构、Prompt工程、需求优先级、产品工作流。

- 开发Solidity智能合约，实现活动创建、状态管理、报名、签到和参与记录核验
- 组织功能测试、缺陷跟踪和回归验证

### 5.4 测试视角

- 梳理报名、签到、权限管理完整业务链路
- 设计正常场景、边界场景、异常场景测试用例

- 修复后执行回归测试，沉淀测试记录

### 5.5 项目成果

- 完成从需求分析、产品设计、开发实现到测试部署的完整流程
- 实现活动发布、在线报名、签到记录上链、参与记录验证
- 支持钱包绑定与区块链数据查询
